# 突破确认综合清单

本文档提供突破信号验证的完整核查清单，用于技术分析的深度参考。

## 突破前核查清单

在确认任何突破前，必须逐项核对以下条件：

### 量能验证

| 检查项 | 标准 | 风险等级 |
|-------|------|---------|
| 突破日量能 | 超过均量 1.5 倍 | 必要条件 |
| 突破后持续性 | 3 日内维持高于均量 | 必要条件 |
| 缩量突破 | 低于 5 日均量 | 高风险信号 |

### 价格验证

| 检查项 | 标准 | 风险等级 |
|-------|------|---------|
| 收盘确认 | 连续 2 日站稳突破位 | 基本要求 |
| 突破幅度 | 超过 3% | 防止毛刺 |
| 刺穿回撤 | 刺穿后快速回落 | 假突破信号 |

### 基本面验证

| 检查项 | 说明 |
|-------|------|
| 基本面支撑 | 突破时基本面/消息面是否有支撑 |
| 大盘环境 | 大盘是否处于可操作环境（避开系统性下跌市） |
| 资金流向 | 主力资金是否配合 |

### 主力行为识别

| 检查项 | 识别要点 |
|-------|---------|
| 庄家对倒 | 分时图是否有明显对倒痕迹 |
| 尾盘操纵 | 突破是否集中在尾盘30分钟 |
| 钓鱼线 | 突破后是否快速回落形成钓鱼线形态 |

## 突破后回踩确认

### 回踩成功信号

- 回踩幅度 < 突破幅度的 50%
- 回踩时量能 < 突破日量能的 40%
- 价格在突破位获得支撑

### 回踩失败信号

- 回踩幅度 > 突破幅度的 50%
- 回踩时放量（量能超过突破日）
- 价格跌破突破位

## A 股涨停板特殊检查

### 封板强度评估

| 换手率 | 信号含义 |
|-------|---------|
| < 3% | 强势，封板资金需求小，筹码稳定 |
| 3%~10% | 正常，多空博弈可控 |
| > 10% | 警示，次日开板概率增加 |

### 连板股检查

- [ ] 是否为新股上市初期（一字板正常）
- [ ] 高位是否出现炸板（涨停打开且未回封）
- [ ] 次日开盘是否低开低走

### 一字板后检查

- [ ] 首个放量大阳线后是否快速封板
- [ ] 封单是否持续增加
- [ ] 是否出现冲高回落、放量出货

## 决策矩阵

| 满足条件数 | 操作建议 |
|-----------|---------|
| 全部满足 | 突破信号可靠性显著提升，可正常操作 |
| 满足 4~5 项 | 降低仓位操作，等待回踩确认 |
| 满足 2~3 项 | 谨慎观望，降低仓位或放弃 |
| 仅满足 1 项或以下 | 放弃信号，避免假突破陷阱 |
