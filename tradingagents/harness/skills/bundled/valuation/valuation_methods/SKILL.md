# 估值方法选择指南

## 概述

估值是连接公司基本面与市场定价的桥梁。没有绝对的"正确"估值方法，不同方法适用于不同行业、不同成长阶段和不同市场环境的公司。本 Skill 梳理 A 股最实用的五种估值方法，分析各自的适用场景、核心优势和致命局限。

## 一、PE（市盈率）

**计算公式**：PE = 股价 / 每股收益（EPS）

**适用范围**：盈利稳定、周期性弱的成熟行业，如消费（食品饮料、家电）、医药（创新药除外）、金融等。

**优势**：直观易懂，计算简单，是 A 股最广泛使用的估值指标。PE 分位数（当前 PE 在历史 PE 分布中的位置）是判断估值高低的重要参考。

**局限**：

- 不适用于亏损公司（负 PE 无意义）
- 不适用于盈利波动大的周期股（钢铁、煤炭在景气高点 PE 最低，实为陷阱）
- 不反映公司的成长性和资产质量
- 容易被会计处理手段操纵（通过非经常性损益虚增 EPS）

**A股实战用法**：使用 PE 时，建议同时参考 **滚动 PE（TTM）** 和 **预测 PE（前向 PE）**，避免被一次性收益干扰判断。同时对比 **申万行业 PE 均值**，偏离度超过 50% 时需有充分理由。

## 二、PB（市净率）

**计算公式**：PB = 股价 / 每股净资产

**适用范围**：金融（银行、保险、券商）、地产、周期股（钢铁、煤炭）和资产较重的公司；也适用于破净股（PB<1）的价值陷阱识别。

**优势**：净资产相对稳定，不受短期盈利波动影响，是重资产公司和金融股的首选估值方法。银行股常用 PB 而非 PE，因为银行利润受拨备调节空间大。

**局限**：

- 不反映公司的盈利能力（低 PB 可能是夕阳行业）
- 净资产质量参差不齐（商誉、应收账款、存货等可能虚高）
- 不适用于轻资产公司（互联网、传媒、知识服务等）

**A股实战用法**：银行股 PB 通常在 0.5~1.5 倍之间波动，低于 0.6 倍常被视为低估但也可能维持多年；破净的地产股需结合 NAV（净资产价值）和销售前景判断。

## 三、PS（市销率）

**计算公式**：PS = 总市值 / 营业收入

**适用范围**：尚无盈利但有收入的成长型公司（电商、SaaS、互联网），以及盈利波动大的公司。

**优势**：收入比利润更稳定，不易被会计处理操纵，适合评估营收增长阶段的公司。

**局限**：不考虑成本结构，无法反映盈利能力的差异。

**A股实战用法**：消费类公司 PS 通常 1~5 倍，科技公司 PS 可高达 10~20 倍但波动极大。收入增速快但尚未盈利的成长股（如新消费品牌、互联网医疗）是 PS 的主要应用场景。

## 四、DCF（现金流折现）

**核心逻辑**：公司价值 = 未来自由现金流的现值之和。

**关键输入**：增长率假设（g）、折现率（WACC）和永续增长率（terminal growth rate）。

**优势**：理论上最严谨的估值方法，反映公司的长期价值创造能力。

**局限**：

- 对假设高度敏感（折现率 ±1% 或增长率假设 ±1% 可能导致估值变化 30%~50%）
- 需要对公司未来多年经营数据做出预测，主观性较强
- 不适用于业绩高度不确定的早期公司

**A股实战用法**：DCF 更多用于机构投资者的内部研究，普通投资者可将其作为估值区间参考而非精确数字。建议进行 **敏感性分析**——列出乐观/基准/悲观三种假设下的估值，形成合理的估值区间。

## 五、PEG 估值法

**计算公式**：PEG = PE / 净利润增速（G）

**优势**：将估值与成长性结合，是成长股估值的核心工具。

**局限**：

- 假设线性外推不合理（高增速通常不可持续）
- 不考虑商业模式和竞争壁垒的差异
- G 的取值（历史增速 vs 预测增速）差异巨大

**A股实战用法**：PEG<1 通常被视为低估，PEG>2 视为高估。但 A 股成长股的 PEG 普遍偏高（市场给予赛道溢价），需结合行业和竞争格局综合判断。PEG 适用于消费、科技等稳定成长行业，不适用于强周期股。

## 六、A股特有的估值参考体系

**历史分位数法**：使用个股或行业指数 PE/PB 的历史区间（过去 5~10 年）判断当前估值在历史中的位置。PE 分位数低于 20% 通常意味着估值偏低。

**股债利差（FED 模型）**：沪深 300 的 PE 倒数（盈利收益率）与十年期国债收益率的差值。差值越大，股票相对债券的吸引力越高，是判断市场整体估值的宏观参考。

**行业对标法**：与海外成熟市场同行业公司进行估值对比（如 A 股银行 vs 美股银行），但需考虑 A 股流动性溢价和成长性差异。

**AH 溢价指数**：同时在 A 股和 H 股上市的公司，AH 溢价率反映了境内外投资者对公司估值的分歧，是判断 A 股估值偏贵的辅助指标。

## 七、方法选择决策树

```
公司是否盈利？
├── 否 → 使用 PS 或用户数/GMV 等业务指标
└── 是 → 公司是周期股吗？
         ├── 是 → 使用 PB 或 EV/EBITDA
         └── 否 → 公司是金融股吗？
                  ├── 是 → 使用 PB
                  └── 否 → 公司是成熟稳定型？
                           ├── 是 → 使用 PE + DCF
                           └── 否 → 使用 PEG + PS
```
