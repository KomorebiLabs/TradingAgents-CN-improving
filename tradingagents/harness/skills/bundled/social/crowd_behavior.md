# 群体行为分析指南

## 概述

行为金融学研究表明，投资者并非理性人，市场错误定价很大程度上源于群体心理偏差。A 股市场以散户为主导，其行为特征与成熟市场的机构主导市场有显著差异。本 Skill 梳理 A 股投资者群体行为的核心模式、常见的行为金融学偏见，以及识别和利用这些偏见的实战方法。

## 一、A 股投资者结构与行为特征

**A 股投资者结构**（截至 2024 年末）：

- 散户（个人投资者）账户数占比超过 99%，但持股市值占比约 45%
- 公募基金 + 私募基金持股市值占比约 25%
- 社保、保险、QFII、北向资金合计约 15%
- 产业资本（上市公司大股东）持股市值约 15%

散户数量庞大、机构占比逐步提升但仍不足一半的格局，决定了 A 股市场的行为特征——高波动性、情绪化交易、短期导向。

**散户 vs 机构的核心行为差异**：

- 散户交易频率是机构的 5~10 倍（高换手率）
- 散户倾向于追涨杀跌（高买低卖），机构逆势布局
- 散户信息获取滞后（消息来源不如机构及时）
- 散户持仓分散，机构持仓集中
- 散户对亏损的容忍度低，频繁止损；机构能承受短期浮亏

## 二、核心行为金融学偏见

**处置效应（Disposition Effect）**：投资者倾向于过早卖出盈利股、长期持有亏损股。这是 A 股散户最普遍的行为偏见，也是导致"赚了蝇头小利、亏了大钱"的根本原因。

克服方法：设置明确的止损线（如 -8% 强制止损）和止盈线（如 +20% 部分止盈），用规则约束情绪反应。

**羊群效应（Herding）**：投资者倾向于模仿他人的行为，当看到大量抛售时也跟着抛售，看到涨停板时追涨买入。A 股的概念炒作中，羊群效应最为典型——某概念出现后，资金快速涌入形成赚钱效应，吸引更多散户追入，泡沫膨胀直至破裂。

识别羊群极端：换手率异常攀升、大量散户股吧发帖讨论、龙虎榜上游资席位活跃。

**锚定效应（Anchoring）**：投资者将某个价格作为"锚点"（如买入价、历史高点），即使公司基本面已发生重大变化，仍以此锚点作为买卖决策依据。例如某股从 50 元跌至 25 元，散户认为"已经腰斩很便宜"而买入，但若公司基本面已恶化，25 元可能仍是昂贵的。

**近期偏差（Recency Bias）**：投资者过度重视近期事件，忽视长期趋势。"最近涨了所以会继续涨"是典型的近期偏差。表现为在热点板块涨至高位后大量追入接盘。

**情绪驱动的过度反应**：A 股对政策消息、市场传闻的反应极为迅速且经常过度。2015 年股灾期间大量个股出现连续跌停，2020 年初疫情爆发后首日大盘暴跌 8%，均是情绪过度反应的典型案例。

## 三、A 股特有的群体行为模式

**"板块轮动中的散户踩踏"**：当某板块开始回调时，大量散户同时止损或止盈，导致板块指数快速下跌，而机构往往在此时逆向吸筹。2022 年光伏板块从高点回落 40% 的过程中，多次出现"一日暴跌后次日反弹"的模式，即散户踩踏后机构入场修复。

**"北向资金信号效应"**：A 股散户和部分内资机构将北向资金流向作为交易信号，形成了北向资金本身反而影响市场行为的"自我实现"机制。若北向资金持续净买入，相关大盘蓝筹会获得更多内资跟买，反之亦然。

**"政策市情绪放大器"**：A 股对政策消息的反应被散户情绪大幅放大。重大利好政策可能引发连续涨停；利空政策（如监管收紧）则引发恐慌性抛售。这种放大效应导致 A 股政策驱动的行情来得快、去得快，波动率远高于基本面变化所应引发的幅度。

**"大股东减持的情绪冲击"**：重要股东（大股东、高管）宣布减持计划，在 A 股市场往往引发显著的情绪冲击。散户将减持解读为"内部人不看好"，即使公司基本面未变，股价也常出现阶段性下跌。

## 四、利用群体行为的实战策略

**逆向投资框架**：

1. 识别群体极端情绪（使用 sentiment_scoring Skill 中的打分卡）
2. 等待情绪极端信号（极度贪婪或极度悲观）
3. 逆向建仓，但分批入场，避免"接飞刀"的单次重仓风险
4. 设定合理的持有期和止损纪律

逆向投资的难点在于"情绪极端后可能更极端"，需要承受短期浮亏的耐心。

**跟随趋势框架**（适用于趋势确认后的顺势交易）：

1. 识别市场共识方向（大势 + 板块 + 个股的趋势一致性）
2. 在趋势回调时买入（而非追高）
3. 用严格止损保护（如回撤 5% 离场）控制风险
4. 趋势破坏时果断离场

趋势跟随策略的核心风险是"假突破"和"趋势突然反转"，需要与量价分析配合。

**事件驱动的情绪博弈**：

1. 重大事件（财报、政策）发生前分析市场预期
2. 事件后观察市场实际反应（超预期 vs 低于预期）
3. 顺势交易反应方向（超预期上涨则顺势做多）
4. 设置事件驱动交易的时间窗口（通常 3~10 个交易日）

## 五、群体行为的量化指标

| 指标 | 含义 | 数据来源 |
|------|------|---------|
| 换手率 | 市场/个股交易活跃度 | 交易所每日公布 |
| 融资融券余额 | 杠杆资金情绪 | 交易所每日公布 |
| 沪深股通净流入 | 外资情绪 | 交易所每日公布 |
| 龙虎榜营业部席位 | 游资活跃度 | 上交所/深交所 |
| 新增开户数 | 散户入场意愿 | 中登公司月度 |
| 偏股型基金发行规模 | 散户间接入市的热情 | 基金业协会月度 |

新增开户数是 A 股最经典的反向指标之一——开户数激增往往是市场顶部的滞后信号，开户数降至冰点往往是市场底部的滞后信号。
